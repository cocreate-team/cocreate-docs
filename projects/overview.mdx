The Cocreate project library is your central command point for every job you work on. From the moment you launch Cocreate, the Home screen greets you with a visual record of all your projects — switch between a thumbnail grid and a sortable list, search by name, create new projects from scratch or directly from a Card Manager transfer, and manage existing ones through rename, delete, and bulk-delete operations. Everything you need to move a job from intake to delivery lives inside a project, and understanding how projects are stored, shared, and recovered when drives change is the foundation of a smooth dailies workflow.

## The Home Screen

The Home screen is your project library. Open it at any time by clicking the **Home** icon in the main navigation.

From the Home screen you can:

- **Switch views** between grid (thumbnail cards) and list (sortable table) using the view toggle in the top-right toolbar.
- **Search** across all your projects using the search field — results update as you type.
- **Create a project** by clicking **New Project** and entering a name, or have Cocreate create one automatically when a Card Manager transfer completes.
- **Rename or delete** any project by right-clicking its card or row. Hold **⌘** or click checkboxes to multi-select projects for bulk deletion.
- **Open a project** with a single click. Unlinked projects (where the `.ccrt` file has moved or the drive is disconnected) display an amber warning flag; click it to open the relink flow described below.

<Note>
  The built-in **Tutorial** project is protected and cannot be deleted. Use it
  to explore Cocreate features with pre-seeded media at any time.

## Portable `.ccrt` Project Files

Every Cocreate project is stored as a single **`.ccrt` file** — a gzipped JSON document that is the complete source of truth for that project. It contains all analysis state: asset metadata, slate reads and transcription results, audio/video sync pairs, folder structure, tags, custom fields, color labels, comments, and documents. Auto-save writes changes continuously in the background, so you rarely need to think about it.

What `.ccrt` files do **not** contain is the media itself. Clips are referenced by file path only, which means:

- **Projects travel freely between machines.** Copy or share a `.ccrt` file and open it on any Mac running Cocreate — all analysis data comes with it.
- **Machine-specific fields are stripped on export.** Paths, device identifiers, and other environment-specific values that could cause confusion on another system are removed when you use **Export Project**.
- **Media stays where it lives.** The project file is small (typically a few megabytes even for large shoots), while media files remain on their original volumes.

To open a `.ccrt` file directly, double-click it in Finder. To export a copy (optionally including sync pairs for handoff to another operator), use **File → Export Project**.

### Importing a Project

When you receive a `.ccrt` file from another operator, drag it onto the Home screen or choose **File → Import Project**. Cocreate shows a preview of the project name and asset count, lets you rename it before import, and then adds it to your library.

## Media Relinking

When you open a project on a different machine, or reconnect a drive that has been renamed or reorganized, some or all of your media may appear offline. Cocreate detects offline assets automatically and displays them with a warning indicator in the media browser.

To relink media, click the **Relink Media** button in the project header or on the Home screen's amber flag. Cocreate scans a folder you choose and proposes mappings using three strategies, tried in order:

| Strategy | How it works |
|---|---|
| **Exact path** | Matches assets whose full file path is identical on the new volume |
| **Filename** | Matches by filename alone, ignoring the parent directories |
| **Fuzzy match** | Compares filenames using similarity scoring and displays a confidence percentage for each proposed match |

Review the proposed mappings, adjust any that are incorrect, and click **Apply**. Managed transcode references relink alongside their source files, and slate images and thumbnails regenerate from stored timestamps — so your analysis data is fully intact once relinking is complete.

## Opening Multiple Projects in Tabs

Cocreate supports a **multi-tab workspace**: open as many projects simultaneously as you need, each in its own tab. Click the **+** button in the tab bar to open another project from the library without closing the one you are already working in.

Each project tab is fully independent and contains three sub-tabs:

| Sub-tab | Purpose |
|---|---|
| **Import Media** | Add new media files and choose which analysis passes to run |
| **Media** | Browse, review, and edit metadata for all imported clips |
| **Export** | Configure and generate NLE project files and media deliverables |

Pane sizes, view state, and player position persist per-project tab, so switching between jobs is instant.

## Roaming Sessions

When you are on set during a live shoot and media is arriving continuously, use a **Roaming Session** to have Cocreate watch a folder and ingest new files automatically as they land. Cocreate monitors the folder in the background, picking up new batches in first-in, first-out order at a low-priority queue that does not interfere with playback or other work.

To start a Roaming Session:

1. Open your project and go to the **Import Media** sub-tab.
2. Click **Start Roaming Session** and select the folder to watch.
3. Leave Cocreate running. Each new batch of files that appears in the folder is ingested and analyzed automatically.

When working without an internet connection, Cocreate detects the airgapped state and disables cloud-dependent processes such as transcription and AI-assisted slate reading, falling back to local-only analysis so processing still proceeds.
