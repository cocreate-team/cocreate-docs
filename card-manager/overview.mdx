Card Manager is Cocreate's dedicated data-wrangling workspace — the place where raw camera media becomes a verified, receipt-backed ingest ready for editorial. Rather than juggling separate tools for copying, checksumming, transcoding, and logging, you do everything in a single pass: add your source cards, configure one or more backup destinations, choose a verification method, optionally generate proxies on the fly, and hit **Add to Queue**. By the time the progress bar reaches 100%, you have a nearline backup, an edit-ready proxy volume, a set of signed receipts, and a running audit trail — all without opening another application.

## The three views

Card Manager is organised into three views, each covering a distinct part of the ingest workflow:

| View | What you do here |
|---|---|
| **Transfer** | Add sources and destinations, set verification and encoding options, configure operator metadata, and queue jobs |
| **Reports** | Review per-transfer receipts, checksum manifests, MHL files, and HTML directory snapshots |
| **Ingest Log** | Browse and filter the per-step operational audit trail; export as CSV |

## Core workflow

Every ingest follows the same sequence:

1. **Add a source** — point Card Manager at a camera card, a media drive, or any folder containing rolls.
2. **Configure destinations** — add a working destination and an optional backup destination. Assign a role to each: **Working** or **Backup**.
3. **Set verification** — choose a checksum method (CRC32, MD5, xxHash, SHA-256, SHA-512, or byte-compare) that matches your facility's requirements.
4. **Configure encoding** (optional) — enable transcode-on-offload to generate DNxHR, ProRes, or H.264 proxies as the copy runs.
5. **Add to queue and run** — Card Manager copies, verifies, and encodes in one pass while writing every step to the Ingest Log.
6. **Review reports** — open the completed job's receipts, checksum manifest, and MHL file directly from the Transfer view.

<Tip>
When a transfer completes, Card Manager automatically creates a Cocreate project populated with the ingested rolls. You can open it immediately from the completed job card — no separate import step required.
</Tip>
