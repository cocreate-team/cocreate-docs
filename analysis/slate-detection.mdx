A slate — the clapperboard filmed at the start (or end) of every take — is the single piece of ground-truth metadata that ties a raw camera file to a specific moment in the script. When Cocreate reads that slate accurately, every downstream step compounds: clips are auto-named with the correct scene and take, multi-camera angles of the same take are grouped together, production sound rolls are matched to the right camera, and Avid or Premiere bins are built with the structure an editor can open and immediately work in. A misread on even one field cascades — a wrong scene number breaks multicam grouping, a wrong roll ID mislabels an entire camera's worth of footage. Cocreate's slate detection pipeline is therefore the highest-leverage stage in the analysis workflow, and it's designed with multiple extraction strategies, confidence scoring, and a corrections pass specifically to minimize the cost of a miss.

## Fields extracted from the slate

Cocreate reads the following fields from every detected clapperboard:

| Field | Example values |
|---|---|
| **Scene** | `47A`, `204D`, `6.5` |
| **Take** | `3`, `12` |
| **Roll** | `A001`, `B07` |
| **Camera** | `A`, `B`, `C` |
| **Date** | `28/04/2025` |
| **Director** | `J. Rivera` |
| **Camera Operator** | `M. Chen` |
| **Production Title** | `CLEARCUT` |
| **Tags** | `Day`, `Nite`, `Int`, `Ext`, `MOS` |

Every extracted field receives an individual **confidence score** from 0.0 to 1.0. Scores below roughly 0.7 are highlighted in the FileViewer and Slate View so you can identify fields that need a quick review before export.

## How slate detection works

Cocreate uses a multi-strategy pipeline — running extraction methods in order of reliability, falling back to the next strategy only when the previous one doesn't produce a high-confidence result.

### Step 1: Transcript-first extraction

Before any video frame is analyzed, Cocreate checks the dialogue transcript for verbal slate callouts — the sound assistant announcing "Scene 47 apple, take 3, marker." If the transcript returns a result with sufficient confidence, Cocreate uses those values and may skip the visual scan entirely. Transcript extraction is fast and reliable for clearly announced takes; it runs alongside the audio track analysis at no extra compute cost.

### Step 2: AI visual slate detection

For clips where the transcript didn't yield high-confidence slate data, Cocreate uses a computer vision model to scan the video frames for a clapperboard. The scanner works through the clip systematically — prioritizing the head and tail of the clip where slates typically appear, then sweeping further into the footage if needed. It exits early once a confident detection is confirmed, so most clips complete quickly.

### Step 3: AI field reading

The best detected slate image is processed by an AI vision model that reads every field on the board and returns a structured result with per-field confidence scores. For tail slates that appear upside down, Cocreate automatically applies a 180° rotation and re-reads the fields.

<Note>
  Cocreate also maintains a fallback path using a local vision model for airgapped deployments where cloud AI is unavailable. Detection accuracy is slightly reduced in airgapped mode but all field extraction still runs locally on-device.
</Note>

### Step 4: Global corrections pass

After all clips have been processed individually, Cocreate runs a multi-phase corrections engine across the whole project. This pass uses timecode-overlap analysis, statistical outlier detection, cross-clip take-sequence validation, and AI re-reads of dubious slates to catch systematic misreads — OCR confusions like `'O'` for `'0'` or `'I'` for `'1'` — and propagate verified values to related clips. The corrections pass runs automatically after analysis completes and again when you trigger **Suggest corrections** from the FileViewer.

## Tail slates

Tail slates (boards filmed at the end of a take, upside down) are handled automatically. The scanner checks the clip's tail during its sweep, and the 180° rotation retry ensures inverted text is read correctly. The decision path for that asset records that a tail slate was used so you can verify the result if needed.

## Reviewing slate results

### Slate View

Switch to **Slate View** (⌘2) to see every clip as a slate thumbnail with its extracted field values displayed beneath. Click any thumbnail to open the Slate Viewer modal, which shows:

- The full-resolution slate crop
- Per-field values alongside their confidence scores
- The extraction method used (transcript or visual AI)

Low-confidence fields appear highlighted in amber.

### FileViewer (List View)

Switch to **List View** (⌘1) to see all assets in the metadata spreadsheet. Slate fields — Scene, Take, Roll, Camera, Tags — appear as editable columns. The confidence level for each field is accessible from the **View slate** option in the right-click context menu.

## Manually editing slate fields

When a field is wrong or missing, click directly on it in the FileViewer to enter edit mode. Type the corrected value and press **Enter** to commit. Cocreate tracks every manual edit and uses user corrections as high-confidence signals in the global corrections pass — your edits help train the outlier detector for similar fields across the project.

You can also edit fields in the Slate Viewer modal by clicking the value next to any field label.

## Applying slate suggestions

Cocreate auto-generates suggestions for uncertain or missing fields based on timecode proximity, take-sequence patterns, and cross-clip analysis. When a suggestion is available, a **suggestion popover** appears on the relevant cell in the FileViewer or on the field in the Slate Viewer. For each suggestion you can:

- **Apply** — Accept the suggested value. The field updates and the suggestion is dismissed.
- **Dismiss** — Reject the suggestion. The field retains its current value and the suggestion is cleared.

To trigger a fresh round of suggestions for the whole project, open the FileViewer context menu and choose **Suggest corrections**. To generate suggestions only for fields that still show "Unknown," choose **Suggest values for unknown fields**.

## Bulk-editing slate fields

To apply the same field value to multiple clips at once:

<Steps>
  <Step title="Select the clips you want to update">
    In the FileViewer, use Cmd-click or Shift-click to select multiple clips. You can also select an entire folder group.
  </Step>
  <Step title="Open the bulk-edit dialog">
    Right-click the selection and choose **Bulk edit**, or press the **Bulk edit** button that appears in the toolbar when multiple clips are selected.
  </Step>
  <Step title="Choose the field and enter the new value">
    Select the field you want to update (for example, **Roll** or **Camera**) and type the value. A preview shows how many clips will be affected.
  </Step>
  <Step title="Apply">
    Press **Apply**. All selected clips update immediately. The edit is undoable with Cmd-Z.
  </Step>
</Steps>

<Tip>
  Bulk-edit is especially useful for drone or MOS clips that don't carry slates. Select all clips from a roll with a known scene range, then batch-fill the Roll and Camera fields to keep your metadata consistent before export.
</Tip>

## Re-running slate detection on specific clips

To re-scan one or more clips after correcting a problem (wrong toggle setting, corrupt frame, missed slate):

1. Select the clip(s) in the FileViewer.
2. Right-click and choose **Rescan slate**.

Cocreate re-runs the full detection pipeline on the selected assets and updates the metadata. Previously extracted values are overwritten by the new result. For clips where the quick scan found nothing, you can also choose **Deep Slate Scan** from the context menu — this runs an uncapped full-video sweep at higher frame density, useful for clips with late or heavily obscured slates.
