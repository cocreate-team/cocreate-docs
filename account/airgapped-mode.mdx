Airgapped mode puts Cocreate into a fully offline operating state: every network socket is closed, all cloud AI calls are suppressed, and the app runs entirely on local resources. It is designed for productions where internet access is unavailable, prohibited, or a security risk — including government and military shoots, studio facilities with strict network policies, and remote locations where connectivity simply isn't reliable. Because airgapped mode is a first-class feature rather than a graceful-degradation fallback, the core dailies workflow remains intact: you can ingest, analyse slates, transcribe dialogue on-device, sync camera and sound, export to your NLE, and generate reports without a single byte leaving the machine.

## When to Use Airgapped Mode

Enable airgapped mode in any of these situations:

- **Secure government or military productions** — facilities that prohibit outbound traffic from workstations handling production media
- **Studio networks with firewall restrictions** — environments where the workstation cannot reach external APIs regardless of your settings
- **Remote or onset locations without internet** — locations where mobile data is unavailable, unreliable, or too slow for cloud transcription
- **Privacy-sensitive projects** — productions where stakeholders require that no footage metadata, dialogue, or slate images leave the local network

## How to Enable Airgapped Mode

<Steps>
  <Step title="Open Settings">
    In the Cocreate menu bar, press **Cocreate → Settings**, or use the keyboard shortcut if one is configured.
  </Step>
  <Step title="Navigate to General">
    Select the **General** tab in the Settings panel.
  </Step>
  <Step title="Toggle Airgapped mode on">
    Locate the **Airgapped mode** toggle and switch it on. Cocreate immediately closes all active network connections and disables the cloud-dependent features listed below. No restart is required.
  </Step>
</Steps>

To return to normal online operation, open **Settings → General** and switch the toggle off. Cocreate reconnects, syncs any buffered usage data, and re-enables cloud features automatically.

## What Still Works in Airgapped Mode

The full dailies pipeline remains operational offline:

| Feature | Airgapped behaviour |
|---------|-------------------|
| **Card Manager (ingest and offload)** | Fully available — transfers, checksums, receipts, ingest log, expected-roll validation |
| **Slate detection** | Uses the bundled YOLO clapperboard model locally via ONNXRuntime — no GPT-4o Vision call |
| **On-device transcription** | Parakeet TDT 0.6B v3 runs locally: Core ML on the Apple Neural Engine on macOS 14+, or ONNX on CPU on Windows 10/11 x64. Produces the same word-level timestamps as cloud transcription. Requires a one-time model download; see below. |
| **Audio/video sync** | Timecode sync and waveform fingerprint sync both work fully offline |
| **Playback and review** | Native hardware decode, J/K/L shuttle, multicam viewer, LUT overlay — all local |
| **NLE export** | Avid `.avb`, Premiere `.prproj`, Resolve `.drp`, XMEML — all generated offline |
| **Reports and receipts** | PDF, CSV, and HTML reports generated locally |
| **Project management** | Create, open, save, export, and relink `.ccrt` files normally |

## What Requires Network Access

The following features are unavailable while airgapped mode is active:

| Feature | Reason |
|---------|--------|
| **Cloud transcription (Deepgram Nova-3)** | Requires outbound connection to Deepgram's API |
| **AI-assisted slate OCR (GPT-4o Vision)** | Requires outbound connection to OpenAI's API |
| **Dashboard publishing** | Requires connection to dashboard.cocreate.so |
| **Subscription sync** | Subscription and billing checks are suspended |
| **Auto-updates** | Update checks and downloads are suppressed |
| **In-app notices** | Server-broadcast messages are not fetched |

<Note>
GPT-4o Vision provides the highest slate-reading accuracy on difficult boards (low light, partial occlusion, non-standard formats). In airgapped mode, Cocreate falls back to the local YOLO detector with deterministic OCR. For most production slates the results are equivalent; for unusually challenging boards, plan a cloud re-analysis pass when connectivity is restored.
</Note>

## On-Device Transcription with Parakeet

When airgapped mode is on, Cocreate automatically routes all transcription jobs to **Parakeet TDT 0.6B v3**, a speech-recognition model that runs locally on your workstation. On macOS 14 Sonoma or later, Cocreate uses the Core ML build on the Apple Neural Engine, which does not compete with the CPU cores handling media decode and analysis. On Windows 10 or 11 x64, Cocreate uses an ONNX build on CPU via `onnx-asr`. Parakeet produces Deepgram-compatible JSON output with per-word timestamps and confidence scores, so every downstream feature that consumes transcripts — dialogue search, transcript panel, dialogue markers in NLE exports — works identically whether the transcript came from Deepgram or Parakeet.

<Warning>
The Parakeet model is not bundled with the installer. The first time you enable on-device transcription, Cocreate downloads the platform-specific model into a per-user runtime cache and verifies each file's SHA-256 checksum. Complete this download **before going onto a secure set** — if the cache is empty when you first enable airgapped mode, the download dialog will prompt you and cannot complete without a network connection. Once downloaded, the model persists across sessions and works fully offline.
</Warning>

On-device transcription is unavailable on macOS 12 and 13, and on Linux. In airgapped mode on those platforms, transcription is skipped and the rest of the analysis pipeline runs normally.

## Usage Buffering

Cocreate meters analysis usage even when offline. While airgapped mode is active, every analysis minute consumed is recorded to an encrypted local buffer on disk. When you next disable airgapped mode and connectivity is restored, Cocreate syncs the buffered usage events to the billing server in the background. This means your usage accounting stays accurate across airgapped sessions without requiring any manual action on your part.

<Note>
Airgapped mode is available on both the **Pro** and **Permafree** plans. Permafree's 2-analysis-minute cap still applies during airgapped sessions — usage is tracked locally and enforced when the buffer syncs.
</Note>
