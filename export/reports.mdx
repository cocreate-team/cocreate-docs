Every production generates paperwork: ingest logs, sync-QC records, codec summaries, and delivery receipts. Cocreate produces all of these automatically from the data it captures during offload, analysis, and sync. No manual spreadsheet entry required. Reports export as PDF, CSV, or HTML depending on the type, and most are available from **File → Export Reports** in the menu bar or from Card Manager's **Transfer Reports** dialog. The sections below cover each report type, what it contains, and where to find it.

## Roll Report (CSV)

The Roll Report is a per-roll summary CSV that replaces the manual ingest log spreadsheet most facilities maintain in Excel. For each camera roll in your project, the report captures:

| Column | Description |
|---|---|
| **Roll name** | Camera roll identifier |
| **Clip count** | Total number of clips on the roll |
| **Total size** | Combined file size of all clips on the roll |
| **Total duration** | Aggregate duration in `HH:MM:SS` |
| **Frame rate** | Source frame rate (e.g., `25`, `23.976`) |
| **Resolution** | Source resolution (e.g., `1920×1080`, `3840×2160`) |
| **First clip** | Filename of the first clip on the roll |
| **Last clip** | Filename of the last clip on the roll |
| **First TC** | Source timecode of the first frame of the first clip |
| **Last TC** | Source timecode of the last frame of the last clip |

To export the Roll Report, open your project and select **File → Export Reports** from the macOS menu bar. Set **Output Format** to **CSV** and **Report Type** to **Roll**, choose an output location, and press **Export**.

<Tip>
  The Roll Report contains the same per-roll fields your facility's ingest log tracks — clip count, size, duration, fps, resolution, and first/last TC — so you can use it as a drop-in replacement for the manual Excel log and distribute it alongside the delivery receipt.
</Tip>

## Media Report

The Media Report provides per-roll sync and timecode QC data derived from Cocreate's analysis and sync passes. It is the digital equivalent of a sound department's sync log. For each roll, the report records:

- **TC type** — time-of-day (TOD) or record-run timecode.
- **Sync reference** — which track Cocreate used as the sync anchor (camera or sound).
- **Sync method** — timecode, waveform, or visual clap.
- **Audio presence** — whether audio tracks were detected on camera files.
- **Auxiliary TC** — any auxiliary timecode track found in the audio file (e.g., from a Zaxcom or Sound Devices recorder).
- **Drift** — measured drift in milliseconds per minute for long sync pairs.
- **Notes** — any flags or warnings generated during the sync pass.

Access the Media Report from **File → Export Reports**, setting the Report Type to **Media Report**. The report exports as CSV. Review it before delivering the project to catch rolls where sync confidence is low or drift exceeds your facility's threshold.

## Project Report (PDF / CSV)

The Project Report is a full-project summary available in both **PDF** (for client delivery and archiving) and **CSV** (for data processing). It contains selectable summary sections:

- **Summary** — total duration, total size, clip count, shoot-day range.
- **Clips** — per-clip metadata table.
- **Reels / Rolls** — roll-level breakdown (mirrors the Roll Report data).
- **Scenes** — scene-level grouping with clip counts and durations.
- **Codec / Format breakdown** — count and duration by codec, container, resolution, and frame rate — useful for conform planning and editorial handoff documentation.
- **Video and audio by day and camera** — duration and clip count cross-tabulated by shoot day and camera letter.

Export the Project Report from **File → Export Reports**. Select PDF or CSV under **Output Format**, then check the sections you want to include before pressing **Export**.

## Contact Sheet (HTML / PDF)

The Contact Sheet generates a visual reference document with clip thumbnails and metadata. Each page of the contact sheet displays a grid of frame grabs alongside clip name, scene, take, camera, roll, and timecode. It is the standard deliverable for DIT-to-colorist or DIT-to-VFX handoffs where a visual clip inventory is required.

Contact sheets are available in both **HTML** (self-contained, offline-browsable) and **PDF** formats. Generate a per-transfer contact sheet from Card Manager's **Transfer Reports** dialog (see below), or export a per-project version from **File → Export Reports**. Use the date range, scene, and camera filters to scope the sheet to a single shoot day or camera before exporting.

## Transfer Reports (Card Manager)

Card Manager includes a dedicated **Transfer Reports** dialog for generating reports scoped to a specific transfer job. Open it from the file icon in the Transfer Queue toolbar. Select a transfer in the queue first — the dialog uses that job's destination folder as the default output location and scopes report data to the assets moved by that transfer.

The dialog exposes the following report types:

| Report type | Description |
|---|---|
| **Shooting Day** | Daily production report with all clips organized by day |
| **Clips** | Detailed list of all clips with metadata and timecodes |
| **Thumbnails** | Visual thumbnail sheet of all captured media |
| **Contact Sheet** | Compact grid view with thumbnails and key information |
| **Volume** | Storage analysis and volume usage breakdown |
| **Folder Structure** | Interactive, navigable treeview snapshot of a folder |

Every type except Folder Structure supports both **HTML** and **PDF** output. Folder Structure is HTML-only.

### Common options

- **Generate MHL (Media Hash List)** — writes an MHL file alongside the report for standard-form checksum receipts.
- **Preview after generation** — opens the HTML report in your default browser once it finishes writing. Available for HTML output.
- **Upload to dashboard** — pushes the generated report (and MHL, if present) to the Cocreate dashboard for the selected organization. Only appears when you are signed in to at least one dashboard organization; when multiple organizations are available, pick which one receives the upload.
- **Output Folder** — defaults to `_reports/` inside the transfer's destination folder. Use **Browse** to change it.

### Folder Structure report

The Folder Structure report replaces the standalone HTML snapshot workflow. It produces a self-contained, browsable HTML tree of a directory — the production receipt for a source drive or a nearline copy — with file counts, sizes, and folder hierarchy. It opens in any browser with no internet connection required.

Two Folder Structure–specific controls appear when this report type is selected:

- **Scan Target** — choose **Drive** to snapshot the transfer's source paths, or **Copy** to snapshot the transfer's destination folder.
- **Include hidden files** — when enabled, dotfiles and other hidden entries are included in the tree.

Each Folder Structure scan is recorded as a **drive_scan** or **copy_scan** event in the transfer's Ingest Log, so the snapshot is traceable back to the roll and operator that produced it.

## Card Manager Receipts

Card Manager generates receipts automatically during and after every verified transfer. These are not end-of-project reports — they are real-time delivery records created at the time of offload.

### Per-transfer TXT logs

Each completed transfer writes a plain-text receipt listing every file that was copied, its checksum, verification result, size, and transfer timestamp. The receipt includes the operator initials, work order, and barcode you entered in the Delivery Info panel. Press **Reports & Receipts** on any completed job card in Card Manager to view and export these logs.

### JSON checksum manifests

Alongside the TXT log, Cocreate writes a machine-readable JSON file containing per-file checksums in the verification method you selected (xxHash, MD5, SHA-256, SHA-512, CRC32, or byte-compare). Use these manifests for automated verification at the facility end or to populate your asset management system.

### HTML directory snapshots

Generate a browsable HTML tree of a source drive or nearline copy from the **Folder Structure** report in the [Transfer Reports](#transfer-reports-card-manager) dialog. Pick **Drive** or **Copy** as the scan target to point the snapshot at the transfer's source paths or destination folder.

### MHL (Media Hash List) files

Enable **Generate MHL** in Verification Settings before starting a transfer to produce an industry-standard MHL file alongside each copy. MHL files are accepted by most archive and QC systems as a formal checksum receipt. Cocreate writes the MHL file to the destination folder automatically at the end of each verified transfer.

## Accessing Each Report Type

| Report | Location |
|---|---|
| Roll Report CSV | **File → Export Reports** → Type: Roll → Format: CSV |
| Media Report CSV | **File → Export Reports** → Type: Media Report → Format: CSV |
| Project Report PDF/CSV | **File → Export Reports** → Type: Project Report |
| Contact Sheet HTML/PDF | **File → Export Reports** or **Card Manager → Transfer Reports** |
| Shooting Day, Clips, Thumbnails, Volume | **Card Manager → Transfer Reports** (select a transfer first) |
| Folder Structure HTML | **Card Manager → Transfer Reports** → Type: Folder Structure |
| Per-transfer TXT logs | **Card Manager** → completed job card → **Reports & Receipts** |
| JSON checksum manifests | Written automatically to the transfer destination |
| MHL files | Enable **Generate MHL** in **Card Manager → Transfer Reports** or in Verification Settings before transfer |
